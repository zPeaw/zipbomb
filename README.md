🎯 Purpose

This project demonstrates how recursive archive compression can lead to exponential decompression growth.

It is designed for:

Cybersecurity students

Defensive security research

Classroom demonstrations

Secure coding awareness

This project must only be used in controlled lab environments.

🧠 What This Project Demonstrates

📈 Exponential growth logic in nested archives

🧵 Multi-threaded GUI processing (Tkinter + threading)

📂 Safe temporary directory isolation

🛑 Controlled cancellation with threading.Event

📊 Log-driven execution tracking

The application visually helps users understand why archive scanning and decompression limits are critical in real-world systems.

🖥️ Features

Modern Dark Themed UI

TR / EN Language Support

Thread-safe worker execution

Timestamped system log

Simulated progress animation

Estimated decompressed size calculation

Automatic temporary file cleanup
